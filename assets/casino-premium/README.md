# High Stakes Casino artwork

Original generated photographic burgundy felt table with leather/walnut rail, engraved burgundy/gold card back, and golden spade trophy with play chips. WebP derivatives are optimized for TV displays. The existing casino lobby photograph and King’s Ison J/Q/K illustrations are reused. Card ranks, suits, pips, scores and names remain real HTML driven by the game; the decorative images contain no game state.

Art direction: private casino room, oxblood felt, walnut, warm amber light and antique gold. Source PNGs were retained in the project session.
