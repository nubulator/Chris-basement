# Game Day photographic assets

The stadium photographs are real photographs, downloaded from Wikimedia Commons on November 17, 2026. Each was proportionally resized to 1600 pixels wide and converted to WebP. No elements were generated, added, or removed. Historical signage appears as photographed and is not a claim about current stadium naming.
