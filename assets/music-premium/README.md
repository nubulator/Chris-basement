# Music Challenge artwork

Original generated artwork for Music Challenge v4.0: a walnut-and-burgundy vinyl listening club and a gold-record award still life. WebP derivatives are sized for TV backgrounds; the existing `../game-room-premium/music-v1.webp` turntable artwork is reused for the setup and question stage. All labels, questions, answers, names and scores are live HTML. No game data is embedded in images.
